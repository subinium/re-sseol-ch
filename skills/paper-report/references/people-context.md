# 사람, 기관, 뒷얘기

커뮤니티 정보글은 "누가, 어디서, 왜 이걸 했나"가 보여서 재밌다. 그 대신 실존 인물을 다루므로 출처 기준이 가장 엄격해야 한다.

## 출처 등급과 쓰는 법

뒷얘기(일화)는 출처 등급에 따라 쓰는 방식이 정해진다.

| 등급 | 출처 | 레포트에서 |
|---|---|---|
| A | 논문 본문·각주·감사의 글, 저자 본인의 글·발표, 기관 공식 발표, 학회 공식 페이지 | 그대로 쓴다 |
| B | 주요 매체의 기사·인터뷰 (원문을 직접 열어 확인한 것) | "~라고 함"으로 전달하고 출처 파트에 매체와 날짜를 적는다 |
| C | 위키백과 등 2차 정리 | 원출처(B 이상)를 찾아 확인했으면 B로 쓴다. 못 찾았으면 "위키백과가 ~를 인용해 정리한 내용"이라고 출처 단계를 밝히거나 뺀다 |
| D | 익명 게시판, 출처 없는 SNS, 검색·요약 도구가 만든 문장 | 쓰지 않는다 |

확인하지 못해 뺀 일화는 최종 보고에 "무엇을 왜 뺐는지"로 적는다. 사용자가 원하면 등급을 밝힌 채로 넣을 수 있다.

## 쓸 수 있는 것

| 항목 | 예 |
|---|---|
| 논문상 소속 | "제1저자는 논문 기준 X대 소속" |
| 기여 분담 | "아이디어 제안은 A, 첫 구현은 B" (저자 기여 각주) |
| 연구 라인 | "이 연구실은 몇 년째 이 문제를 팜" (연구실 페이지, 논문 목록) |
| 대표 전작 | "교신저자 전작이 그 유명한 Y임" |
| 여러 논문에 걸친 등장 | "2014년 전작 제1저자가 4년 뒤 후속작 저자로 다시 나옴" |
| 공개된 경력 이동 | "원래 A사에 있다가 B로 옮김" (날짜 필수) |
| 수상, 학회 결과 | "최우수 논문상 받음" |
| 공개 발언 | "저자가 행사에서 ~라고 말함" |

## 쓰지 않는 것

- 사생활: 가족, 건강, 종교, 연애, 거주지, 출신 배경
- 루머와 카더라, 등급 D 출처
- 연봉, 이적 조건 같은 거래 조건
- 동기 추측: "경쟁사를 의식해서 서둘러 냈을 것"
- 국적, 인종, 성별로 연구를 설명하는 것
- 조롱이나 인신공격

애매하면 뺀다. 없어도 글은 성립한다.

## 조사 순서

1. 논문 첫 페이지 저자란과 각주를 읽는다. 공동 제1저자, 교신저자, 소속 번호, "작업 당시 소속" 표기를 원장에 적는다.
2. `lineage.md`의 저자 정보를 본다. 동명이인이 섞일 수 있으니 대표 논문이 분야와 맞는지 확인한다.
3. 전작·후속작 저자 목록과 교차 비교한다. 동일인 판단은 이름만으로 하지 않고 메일 아이디, 소속 이력 같은 근거를 원장 P 항목에 적는다.
4. 제1저자와 교신저자 위주로 연구실 페이지, 기관 발표, 주요 매체 기사를 찾는다.
5. 학회 리뷰가 공개돼 있으면 결정과 핵심 지적 1~2개를 가져온다.

저자가 10명 이상이면 제1저자, 교신저자, 기관 단위로 요약한다.

### 컨소시엄 논문

수백 명이 알파벳순으로 이름을 올린 논문(대형 실험 협력단 등)은 저자 순서가 기여도를 뜻하지 않는다. "제1저자"라는 말을 쓰지 않고 협력단 이름과 규모(저자 수, 참여 기관 수)로 소개한다. 누가 무엇을 했는지는 협력단의 공식 발표나 수상 기록에 나온 만큼만 쓴다.

### 수상과 분쟁

상이 저자 일부에게만 갔으면 수상 기관의 공식 발표 문구대로 쓴다. 특허 분쟁이나 선취권 다툼은 법원·특허청 결정이나 기관 공식 발표 같은 날짜 박힌 공식 기록만 쓰고, 누가 옳은지나 동기는 쓰지 않는다. 금액 같은 거래 조건은 쓰지 않는다.

## 문장 예시

좋음:
```
이번 논문은 [기관] [연구실]에서 나옴 <!-- P1 -->
교신저자 [이름]은
[연도]에 [대표 전작]을 낸 사람임 <!-- P3 -->
```

나쁨:
```
[이름] 교수가 [경쟁사]한테 밀려서 칼 갈고 낸 논문임
```
동기 추측이고 출처가 없다.

## 변하는 정보

- 소속은 "논문 기준"과 "현재"를 구분한다. 현재 소속은 조회 날짜와 출처를 원장에 적는다.
- 근황은 제목이나 첫 줄에 기준 시점을 박는다. 예: "8명 근황 (2024년 3월 기준)".
