# 그림

그림은 논문 인용이 먼저다. 독자는 직접 만든 요약표보다 논문이 실제로 뭐라고 했는지를 보고 싶어 한다. 직접 만든 정리 이미지(`make_graphic.py`, `g_` 파일)는 한 레포트에 1장, 글 앞부분에서 전체 지도(척추나 계보)를 보여줄 때만 쓴다. 2장 이상이면 검사에서 경고한다. 나머지는 원문 그림·표, 원문 문단 인용 크롭, 전작·후속작 그림으로 채운다. 본문 그림이 없는 논문(제안·관점형, 이론형 등)은 설명하는 문장을 그대로 자른 인용 크롭이 주 재료다.

목표는 내용 파트의 70% 이상에 1장, 전체 8장 이상이다 (60% 미만이거나 8장 미만이면 검사에서 경고). 본문 그림이 적은 분야(생물·물리 저널은 본문 그림이 4~5장인 경우가 많다)는 보충자료 그림, 전작·후속작 그림, 원문 문단 인용 크롭으로 채운다. 채울 수 없으면 경고를 받아들이고, 의미 없는 그림을 넣지 않는다. 그림은 "뭘 봐야 하는지" 한 줄과 짝을 이뤄 설명을 뒷받침한다.

## 종류와 만드는 법

| 종류 | 만드는 법 | 파일명 |
|---|---|---|
| 원문 그림, 표 | `extract_figures.py <폴더>` 자동 크롭 | `fig1_p3.png`, `tab2_p8.png` |
| 잘못 잘린 그림, 그림 일부, 누운 그림 | `pages/`의 페이지 이미지를 보고 `crop --page N --bbox x0,y0,x1,y1` (페이지 비율 0~1), 필요하면 `--rotate 90` | `fig4_its.png` |
| 원문 문단 인용 | `quote --page N --start "첫 줄 구절" --end "끝 줄 구절"`. 구절은 인쇄된 한 줄 안의 2~6단어 (`text.txt`에서 줄바꿈 하이픈이 없는 곳을 고름). 단을 넘는 문단은 단마다 따로 자르거나 한 단만 씀. 한 단짜리 논문·초록은 `--full-width`. 표도 캡션 첫 구절부터 마지막 칸 구절까지 `--full-width`로 자를 수 있음 | `q_registry.png` |
| 수식 | `crop`으로 식 한 줄 | `eq1.png` |
| 제목·저자부 | `crop --page 1` | `p1_header.png` |
| 전작·후속작 그림 | 그 논문을 `fetch_paper.py`로 받고, 그 폴더에서 `crop --dest <본 레포트 폴더>` | `prior_2014_<저자>.png`, `next_2018_<이름>.png` |
| 계보 요약 또는 척추 지도 (1장만) | `make_graphic.py <폴더> spec.json` | `g_lineage.png`, `g_spine.png` |

자동 크롭은 반드시 열어서 확인한다. 옆 단 침범, 캡션 누락, 절 제목 딸림, 잘림이 흔하다.

## 고르는 기준

우선순위:
0. 그 파트가 설명하는 바로 그 문장이나 표 (인용 크롭). 설명 옆에 원문이 있으면 독자가 과장 여부를 직접 확인할 수 있음
1. 핵심 개념을 한 장으로 보여주는 구조도
2. 추상 개념을 구체 예시로 보여주는 그림 (부록 시각화, 사례)
3. 결과 비교 표나 그래프
4. 전작의 대표 그림 (연대기 파트)
5. 한계나 실패 사례

표는 필요한 행만 말로 짚어 준다. 표 전체를 붙였으면 "맨 아래 두 줄이 이번 방법임"처럼 볼 곳을 알려준다.

## 설명(alt) 쓰는 법

형식: `![무엇을 보여주는지 (출처)](figures/파일.png)`
- 이번 논문 그림이면 원문 표기대로 `(Figure 4)`, `(Fig. 2b)`, `(보충자료 Fig. S3)`. 다른 논문이면 `(Sutskever 외 2014)`.
- 인용 크롭은 `원문 N절. <그 문단이 하는 말 한 줄>` 형식으로 쓴다.
- 무엇을 보여주는 그림인지만 쓴다. 캡처 방식(잘랐음, 회전했음, 일부만), 사용 허락, "원 논문에서 가져옴" 같은 말은 설명에도 본문에도 쓰지 않는다.
- 바로 앞 줄에 "뭘 봐야 하는지"를 쓴다. 예: "가로가 영어 원문, 세로가 프랑스어 번역임".

## 정리 이미지 스펙

레포트당 1장이다. 원문 표를 한국어로 옮긴 표, 분야별 비교표처럼 원문을 대신하는 정리짤은 만들지 않는다. 원문 표를 자르고 볼 곳을 말로 짚는다. 직접 만든 이미지의 모든 값도 원장에 있어야 한다. `source`는 이미지 아래에 찍히는 독자용 출처 한 줄이다.

```json
{"type": "timeline", "name": "lineage", "title": "번역기에서 GPT까지, 한 장 요약",
 "source": "출처: 각 논문 arXiv 최초 공개일 기준",
 "items": [{"year": "2014", "label": "seq2seq", "org": "Google", "note": "RNN으로 문장을 통째로 읽고 번역"},
           {"year": "2017", "label": "트랜스포머", "org": "Google Brain", "note": "어텐션만 남김", "highlight": true}]}
```

척추 지도는 `compare` 형식으로 그린다. 논문이 짚은 문제와 논문이 내놓은 답을 한 표에 둔다.

```json
{"type": "compare", "name": "spine", "title": "아이디어가 공짜가 되면 막히는 네 곳",
 "source": "원 논문 2~4장을 이 글 기준으로 묶은 것",
 "columns": ["", "막히는 곳", "논문이 내놓은 부품"],
 "rows": [["①", "검증이 비쌈", "실험을 서비스로, 데이터 4단계 시장"]], "highlight_col": 1}
```

## 저작권

논문 그림의 저작권은 각 논문에 있다. 레포트를 공개하려는 사용자에게는 논문 라이선스를 확인하라고 최종 보고에서 알린다. 레포트 본문에는 쓰지 않는다.
