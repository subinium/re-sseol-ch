# 기획서: Attention Is All You Need

## 판단
- 유형: 해결형 (근거: 초록 "We propose a new simple network architecture, the Transformer", F1)
- 날짜 기준: arXiv 최초 공개
- 독자 친숙도: 모두 앎 (GPT를 통해). 트랜스포머라는 이름은 업계만 앎
- 지금 사회에서의 위치: 피인용 약 19만 회(L7, 2026-09 기준), 저자 8명 중 7명이 AI 회사 공동창업자(W1, 2024-03 기준), GPT·BERT·ViT의 뼈대(L12 L5 L6)
- 도입 질문: "GPT의 T가 뭔지 앎?" → "왜 번역기 부품이 GPT 뼈대가 됐나"는 파트 21에서
- 마지막 답: 파트 22에서 T를 더 정확히 답함. 트랜스포머는 인코더·디코더 두 쪽이고 GPT는 디코더 쪽(다음 토큰 예측)임
- 맺음: 파트 23. 지금 = 바이브코딩이 콜린스 2025 올해의 단어(W4), GPT-4가 트랜스포머 기반(L11) / 앞을 가리킴(자리 잡은 기술) = n² 비용과 2017년 결론의 숙제(F15 F20), 원저자 발언(W2) → 관전 포인트 / 3줄 요약으로 닫음
- 기대 vs 결과 (선택): 번역 점수 2점 넘게, GPU 8장 서버 한 대, 다음 계획은 다른 모달리티(F18 F16 F20) vs 피인용 19만 회, 7명 창업(L7 W1)

## 밑밥과 회수
- 도입 질문의 답을 미룸 (파트 2) → GPT-1이 트랜스포머를 고른 이유 (파트 21, L21)
- "Sutskever란 이름 기억해두셈" (파트 3) → GPT-1 저자 목록의 그 사람 (파트 21, P2)
- "이 n²은 뒤에서 다시 나옴" (파트 7) → 이미지에서 문제가 된 n² (파트 19, L22)
- "번역 점수 2점" 기대 쪽 (파트 2) → "사전에 새 단어가 올라가는 데까지" (파트 23)

- "갈래 얘기는 뒤에서 다시 나옴" (파트 10) → 멀티헤드가 필요한 이유 (파트 13)
